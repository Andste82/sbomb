sbomb

An evidence-based SBOM generator that reconstructs the software composition of CMake build artifacts.

Install

curl -fsSL https://andste82.github.io/sbomb/install.sh | sh

Windows, in PowerShell:

irm https://andste82.github.io/sbomb/install.ps1 | iex

A particular version

curl -fsSL https://andste82.github.io/sbomb/install.sh | sh -s -- --version v0.12.0

Both scripts verify the download against the release's SHA256SUMS before installing it, and neither offers a way to skip that. Pass --with-sbom to install the release's own CycloneDX document beside the binary.

Read it first

Piping a script from the network into a shell is worth being suspicious of. These are short and plain: install.sh and install.ps1. They are published from the repository by a workflow, so what is served here is what is in the tree.
